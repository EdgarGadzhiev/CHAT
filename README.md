# CHAT — Telegram WebApp

Городская мобильная платформа: чаты, комнаты, знакомства, Нуркоины и городские сервисы.

## Стек

- Vite
- Vanilla JavaScript (ES modules)
- CSS
- Telegram WebApp API
- Supabase — backend/database (подключим следующим этапом)
- YooKassa — платежи (подключим после backend)

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно `http://localhost:5173`.

Для обычной разработки интерфейса этого достаточно.

### Telegram WebApp

Telegram WebApp должен работать по HTTPS, когда он запускается внутри Telegram. На локальном компьютере сначала можно разрабатывать обычным браузером. Для проверки именно внутри Telegram позже подключим тестового бота и HTTPS-домен.

## План разработки

1. Базовый UI и навигация — готово
2. Supabase: пользователи и профили
3. Telegram авторизация и серверная валидация initData
4. Реальные комнаты и сообщения через Supabase Realtime
5. Модерация: бан, мут, жалобы, фильтр сообщений
6. Нуркоины и безопасный ledger транзакций
7. ЮKassa через backend/webhooks
8. Знакомства 18+
9. Подарки, цветные ники и конкурсы
10. Городские сервисы, объявления и афиша
11. Информер и платные размещения
12. Книги и онлайн-читалка
13. Админ-панель
14. Тестирование, безопасность и деплой

## Важно

Секреты Telegram Bot API и YooKassa нельзя помещать во frontend. Они будут использоваться только на серверной стороне/Edge Functions.
