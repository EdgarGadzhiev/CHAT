# CHAT — Telegram Mini App

Frontend городского приложения, которое открывается прямо внутри Telegram.

## Что используем

- **React + TypeScript** — интерфейс и типобезопасная логика.
- **Vite** — быстрый dev-сервер и production-сборка.
- **CSS** — собственный mobile-first дизайн без тяжёлого UI-фреймворка.
- **Lucide React** — аккуратные иконки.
- **Telegram WebApp API** — интеграция с Telegram и получение данных текущего пользователя.

Telegram Mini Apps официально строятся как веб-приложения на JavaScript и могут открываться внутри Telegram. Скрипт Telegram WebApp подключается в `index.html`; данные из `initDataUnsafe` пока используются только для визуального превью и не считаются доверенными. Для будущей авторизации `initData` будет проверяться на сервере.

## Запуск локально

### 1. Установить Node.js

Рекомендуется **Node.js 22 LTS**. Для актуального Vite также подходит Node.js 20.19+.

Проверить:

```bash
node -v
npm -v
```

### 2. Скачать репозиторий

```bash
git clone https://github.com/EdgarGadzhiev/CHAT.git
cd CHAT
```

### 3. Установить зависимости

```bash
npm install
```

### 4. Запустить dev-сервер

```bash
npm run dev
```

Vite покажет локальный адрес, обычно:

```text
http://localhost:5173
```

Открывать его можно в браузере для разработки. В обычном браузере Telegram-данных пользователя не будет, поэтому приложение покажет режим `Гость`.

### 5. Проверить production-сборку

```bash
npm run build
```

Если команда завершилась без ошибок, production-файлы будут в `dist/`.

Для просмотра сборки:

```bash
npm run preview
```

## Как протестировать именно внутри Telegram

Для обычного Telegram WebApp нужен доступный по HTTPS URL. После того как frontend будет размещён, URL можно будет подключить к боту через @BotFather.

На следующем этапе настроим:

1. Telegram-бота.
2. Main Mini App / Menu Button.
3. HTTPS-домен.
4. Серверную проверку Telegram `initData`.
5. Реальную авторизацию пользователя.

Не вставляй токен бота или секреты YooKassa во frontend. Секретные ключи будут использоваться только на backend.
